Key architectural decisions

  • LLM for language, code for math. LLMs parse briefs and write prose from exact fact sheets; every score, price, and impression is deterministic Python/SQL. No number in any output is model-generated.
  • Two-layer profiles. All 66,978 profiles are rule-based and free; LLM polish runs only for the ~15 screens in a final package (cached) — 1 API call instead of ~1,675.
  • Honest failure modes. Missing budget/duration/date → explicit unconstrained/per-day/unchecked behavior with caveats. Filters that would empty the pool are skipped with warnings, never silently applied or silently dropped.
  • Overlap-aware reach. Hard clusters (same stop/corridor) decay at 0.5ⁿ; soft corridor overlap (stop-set Jaccard) discounts further. Reports show standalone vs marginal per screen.
  • Scale-tested. Greedy selection pre-filters to top-500 by raw efficiency with an early budget stop — 0.04s at 37K candidates (was 2+ hours before the fix). Full runs verified on all 6 real briefs.
